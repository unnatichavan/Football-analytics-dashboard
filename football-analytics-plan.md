# Football Player Performance Analytics Dashboard — Implementation Plan

## Top-Level Overview

**Goal:** Build a portfolio-quality, interactive football (soccer) analytics dashboard using Python and Streamlit that lets users explore, filter, and compare synthetic player statistics across multiple teams, positions, and seasons.

**Scope:**
- Four deliverable files: `app.py`, `football_players.csv`, `requirements.txt`, `README.md`
- One optional helper script: `generate_data.py` (produces the CSV reproducibly)
- Synthetic dataset of ≥ 100 players across 8 teams, 4 positions, 3 seasons
- Five dashboard pages: Overview, Player Analysis, Team Analysis, Position Analysis, Data Table
- Sidebar with cascading filters (season → team → position → player)
- Dark green football-inspired Streamlit theme

**Non-goals:**
- No live API integrations or external data fetching
- No user authentication or database persistence
- No machine-learning models

---

## Dataset Schema

File: `football_players.csv`
Generated by: `generate_data.py` using `numpy.random.seed(42)` for reproducibility.

| Column | Type | Description |
|---|---|---|
| `player_id` | int | Unique identifier (1–N) |
| `player_name` | str | Synthetic full name |
| `team` | str | One of 8 fictional club names |
| `position` | str | GK / DEF / MID / FWD |
| `season` | str | "2021-22", "2022-23", "2023-24" |
| `age` | int | 17–36 |
| `appearances` | int | 1–38 |
| `minutes_played` | int | appearances × ~70–90 min |
| `goals` | int | Position-weighted random (FWD > MID > DEF > GK) |
| `assists` | int | Position-weighted random |
| `shots` | int | goals + random offset (shots ≥ goals) |
| `shots_on_target` | int | Between goals and shots |
| `passes` | int | Position-weighted (DEF/MID > FWD > GK) |
| `pass_accuracy` | float | 60–95 % |
| `tackles` | int | Position-weighted (DEF > MID > FWD > GK) |
| `interceptions` | int | Similar weight to tackles |
| `yellow_cards` | int | 0–8 |
| `red_cards` | int | 0–2 |
| `rating` | float | 5.0–9.5 (2 d.p.) |
| `nationality` | str | One of ~20 synthetic nationalities |

**Total rows:** 120 players × 3 seasons = **360 records** (one row per player-season).

---

## KPI Calculations (Overview Page)

All KPIs are computed from the **filtered** DataFrame at runtime — nothing is hardcoded.

| KPI Card | Calculation |
|---|---|
| Total Players | `df['player_id'].nunique()` |
| Total Goals | `df['goals'].sum()` |
| Total Assists | `df['assists'].sum()` |
| Total Minutes Played | `df['minutes_played'].sum()` |
| Average Player Rating | `df['rating'].mean()` rounded to 2 d.p. |

## Project Structure

```
football-analytics-dashboard/
│
├── app.py                  # Main Streamlit application
├── generate_data.py        # Reproducible synthetic data generator
├── football_players.csv    # Pre-generated dataset (committed to repo)
├── requirements.txt        # Python dependencies
└── README.md               # Setup, run, and deploy instructions
```

`app.py` is organised into clearly separated sections / functions:

- `load_data()` — reads CSV, validates columns, handles missing values
- `apply_filters()` — cascading sidebar filter logic
- `render_overview()` — KPI cards + top-5 performers bar chart
- `render_player_analysis()` — comparison selector, scatter plots
- `render_team_analysis()` — team aggregation bar charts
- `render_position_analysis()` — position breakdown charts
- `render_data_table()` — searchable table + CSV download
- `main()` — page router, theme injection, sidebar

5. Assemble into a `pandas.DataFrame`, enforce dtypes, clip to valid ranges
6. Write to `football_players.csv` with `index=False`
7. Print a confirmation message: row count and column list

**Relevant Context:** NumPy seed 42, position weights ensure realism (GK scores 0–1 goals, FWD scores 5–25).
